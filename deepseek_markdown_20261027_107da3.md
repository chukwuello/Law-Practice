## ⚖️ Core Principle

> **Facts are pleaded; evidence is proved.**  
> Pleadings contain *material facts* only—never the evidence by which they are to be proved.

---

## 🧭 How to Use This Repository

1. **For AI-assisted drafting**: Start with the relevant `SKILL.md` file in the skill folder.
2. **For legal research**: Refer to `docs/` for the pleadings–evidence distinction and `statutes/` for statutory provisions.
3. **For drafting precedents**: Use the templates in `sample-drafts/`, adapting facts, names, and jurisdiction-specific rules.
4. **Always verify**: All citations, statutes, and authorities must be independently checked before filing or relying on any output.
